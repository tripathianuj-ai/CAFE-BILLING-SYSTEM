# CAFE-BILLING-SYSTEM
A Python Tkinter-based Cafe Billing System (POS) that manages customer details, menu selection, real-time billing, GST calculation, and digital invoice generation.

☕ Cafe Billing System

Python & Tkinter Based Point of Sale (POS) Application

📌 Overview

Cafe Billing System is a desktop-based Point of Sale (POS) application developed using Python and Tkinter.

The application is designed to simplify the basic billing workflow of a café by allowing users to enter customer details, select menu items, calculate the total amount, apply 18% GST, and generate a digital bill through a simple graphical user interface.

This project demonstrates the practical application of Python programming concepts to solve a real-world business problem.

---

✨ Features

- 👤 Customer Name & Mobile Number
- 🍕 Menu-based item selection
- ➕ Multiple item addition
- 💰 Real-time order total
- 🧾 Automatic bill generation
- 📊 18% GST calculation
- 📅 Automatic date & time
- 💳 Support multiple payment methods:
    - Cash
    - UPI
    - Card
- 🎫 Generate a unique bill number
- 🔄 Clear/Reset functionality
- ❌ Exit functionality
- 🖥️ Simple and user-friendly GUI

---

🧮 Billing Logic

Subtotal = Sum of selected item prices

GST = Subtotal × 18%

Grand Total = Subtotal + GST

The generated bill includes:

- Café name
- Customer details
- Ordered items
- Item prices
- Subtotal
- GST
- Grand total
- Date and time
